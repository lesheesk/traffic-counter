# 🔄 Миграция на ONNX Runtime

## Что изменилось

Проект мигрирован с PyTorch/Ultralytics на ONNX Runtime для уменьшения размера исполняемого файла.

### Изменения:

1. **Удалены зависимости:**
   - `torch` (~200-300 МБ)
   - `torchvision` (~50-100 МБ)
   - `ultralytics` (~50 МБ)

2. **Добавлены зависимости:**
   - `onnxruntime` (~20-30 МБ)

3. **Результат:**
   - Размер exe: ~50-80 МБ (вместо 350-500 МБ)
   - Быстрее запуск и работа
   - Меньше зависимостей

## Первый шаг: Конвертация моделей

Перед использованием нужно конвертировать модели из `.pt` в `.onnx` формат.

### Вариант 1: Используя скрипт (рекомендуется)

1. **Временно установите ultralytics для конвертации:**
   ```batch
   pip install ultralytics
   ```

2. **Запустите скрипт конвертации:**
   ```batch
   python convert_to_onnx.py
   ```

3. **После конвертации можно удалить ultralytics:**
   ```batch
   pip uninstall ultralytics torch torchvision -y
   ```

### Вариант 2: Вручную

```python
from ultralytics import YOLO

# Конвертация одной модели
model = YOLO('yolov8s.pt')
model.export(format='onnx', imgsz=640, simplify=True, opset=12)
```

## Использование

1. **Установите зависимости:**
   ```batch
   pip install -r requirements.txt
   ```

2. **Убедитесь, что у вас есть .onnx модели:**
   - `yolov8n.onnx`
   - `yolov8s.onnx`
   - `yolov8m.onnx`
   - и т.д.

3. **Настройте config.py:**
   ```python
   YOLO_MODEL = "yolov8s.onnx"  # вместо yolov8s.pt
   ```

4. **Запустите приложение:**
   ```batch
   python main.py
   ```

## Различия в работе

### Преимущества:
- ✅ Меньший размер исполняемого файла
- ✅ Быстрее запуск
- ✅ Меньше зависимостей
- ✅ Производительность примерно такая же

### Отличия:
- Модели должны быть в формате `.onnx` (не `.pt`)
- Модели должны находиться рядом с исполняемым файлом или в текущей директории
- Не требуется установка PyTorch

## Сборка .exe файла

После миграции на ONNX:

1. **Запустите сборку:**
   ```batch
   build.bat
   ```

2. **Размер exe будет примерно:**
   - Старый (PyTorch): 350-500 МБ
   - Новый (ONNX): 50-80 МБ

3. **Не забудьте скопировать .onnx модель рядом с exe файлом!**

## Проблемы и решения

### Ошибка: "Model file not found"

**Решение:** Убедитесь, что файл модели `.onnx` находится в той же директории, что и скрипт/exe, или укажите полный путь в `config.py`.

### Ошибка: "ONNX model format error"

**Решение:** Убедитесь, что модель была правильно конвертирована. Попробуйте конвертировать заново.

### Низкая производительность

**Решение:** ONNX Runtime использует CPU по умолчанию. Для GPU можно использовать:
```python
providers = ['CUDAExecutionProvider', 'CPUExecutionProvider']
```
Но это потребует дополнительных DLL для CUDA.
