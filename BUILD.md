# 📦 Инструкция по сборке исполняемого файла

## Сборка .exe файла для Windows

Для создания исполняемого файла, который можно запускать на любом Windows компьютере без установки Python и зависимостей.

### Способ 1: Автоматическая сборка (рекомендуется)

1. **Запустите скрипт сборки:**
   ```batch
   build.bat
   ```

2. **Дождитесь завершения сборки** (может занять 5-10 минут)

3. **Исполняемый файл будет в папке:** `dist\traffic-counter.exe`

### Способ 2: Ручная сборка

1. **Установите PyInstaller:**
   ```batch
   pip install pyinstaller
   ```

2. **Запустите сборку:**
   ```batch
   pyinstaller build.spec
   ```

   Или используйте команду напрямую:
   ```batch
   pyinstaller --name=traffic-counter --onefile --console --hidden-import=cv2 --hidden-import=numpy --hidden-import=ultralytics --hidden-import=torch --hidden-import=config --collect-all=ultralytics --collect-all=torch main.py
   ```

## Использование собранного .exe файла

### На компьютере, где собирали:

1. Скопируйте `dist\traffic-counter.exe` в удобное место
2. (Опционально) Создайте файл `config.py` рядом с exe для переопределения настроек
3. Или настройте переменные окружения
4. Запустите `traffic-counter.exe`

### На другом Windows компьютере:

1. **Скопируйте файл:**
   - `traffic-counter.exe` (config.py уже встроен в exe)

2. **Настройте конфигурацию:**
   
   **Вариант А: Через config.py**
   - Скопируйте `config.py` в ту же папку, что и `.exe`
   - Отредактируйте `config.py` и укажите свой RTSP_URL

   **Вариант Б: Через переменные окружения**
   ```batch
   set RTSP_URL=rtsp://admin:password@192.168.1.64:554/Streaming/Channels/101
   traffic-counter.exe
   ```

3. **Запустите:** `traffic-counter.exe`

## Важные замечания

### Модели YOLO

- Модели YOLO (*.pt файлы) будут автоматически загружены при первом запуске
- Они будут сохранены в домашней директории пользователя (обычно `C:\Users\<username>\AppData\Roaming\Ultralytics`)
- Размер первой загрузки: ~6-50 МБ (в зависимости от модели)

### Размер файла

- Итоговый .exe файл может быть достаточно большим (200-500 МБ)
- Это нормально, так как в него включаются все зависимости (PyTorch, OpenCV, YOLO и т.д.)

### Производительность

- .exe файл запускается немного медленнее, чем обычный Python скрипт
- Это нормально из-за процесса распаковки

### Консольное окно

- По умолчанию отображается консольное окно с логами
- Если хотите скрыть консоль, измените в `build.spec`: `console=False`

## Устранение проблем

### Ошибка при запуске: "Не найдены DLL файлы"

- Убедитесь, что используете правильную версию PyInstaller (последнюю)
- Проверьте, что все зависимости установлены перед сборкой

### Ошибка: "Модель не найдена"

- Модели загружаются автоматически при первом запуске
- Убедитесь, что у приложения есть доступ в интернет для первой загрузки
- Или скопируйте модель вручную в папку с .exe

### Большой размер файла

- Это нормально для приложений с PyTorch и OpenCV
- Можно попробовать использовать `--exclude-module` для исключения ненужных модулей

## Оптимизация размера

Если нужно уменьшить размер файла, можно:

1. **Использовать UPX сжатие** (уже включено в build.spec)
2. **Исключить ненужные модули:**
   ```batch
   --exclude-module=matplotlib --exclude-module=jupyter
   ```
3. **Использовать более легкую модель YOLO** (yolov8n.pt вместо yolov8m.pt)

## Требования к системе

- Windows 7 или выше (64-bit)
- Минимум 4 ГБ оперативной памяти
- Свободное место на диске: ~500 МБ (для .exe файла)
